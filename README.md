## Features

-   Add, view, search, update and delete contacts
-   Validate exactly 10-digit phone numbers
-   Prevent duplicate phone numbers
-   Load and save contact records using CSV file handling

## Requirements

-   Python 3.8 or later
-   No third-party Python packages required

## Run

Open a terminal in the `codebase` folder and execute:

``` bash
python contact_management.py
```

The application reads `contacts.csv` at startup and saves changes to it.

## Sample data notice

The supplied CSV contains 30 fictional demonstration records. Email
addresses use the reserved `example.test` domain. The phone numbers are
sample placeholders for testing and should be replaced with real contact
details only when appropriate.

## Concepts

Functions, lists, dictionaries, loops, conditional statements, input
